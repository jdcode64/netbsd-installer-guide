    📑 Guía Paso a Paso para Seguir desde el Celular (Triple-Boot)
    Regla de Oro: En sysinst NUNCA selecciones Use entire disk. Selecciona siempre Edit GPT partitions y utiliza únicamente la partición libre para NetBSD.

    1. Identificación de particiones en NetBSD:

    Tu disco NVMe se identifica como ld0:

    Partición 1 (EFI ESP)      -> GPT slice 1 (200MB, FAT32)
Partición 3 (Windows 11 C:) -> GPT slice 3 (239GB, NTFS) -> NO TOCAR
Partición 5 (Datos D:)      -> GPT slice 5 (100GB, NTFS) -> NO TOCAR
Partición 6 (Debian Linux)  -> GPT slice 6 (100GB, ext4)  -> NO TOCAR
Partición 8 (Libre)         -> Asignar a NetBSD FFS (Mount point /)

    2. Instalación 100% Offline (Sets descargados):

    Los paquetes están listos en la ISO o en tu carpeta local:

    • Opción ISO en USB: sysinst montará la unidad automáticamente al seleccionar CD-ROM / DVD / USB installer image.
    • Opción carpeta sets_11.0: Si los copiaste a un pendrive FAT32, elige Unmounted fs -> partición sd0e (tipo msdos) -> carpeta /sets_11.0.

    3. Configuración del Arranque Triple en Debian:

    Para no modificar el inicio de Windows ni sobreescribir el cargador de Debian:

    1. En sysinst, elige Do not change the bootcode.
    2. Al finalizar la instalación de NetBSD, reinicia e inicia tu Debian habitual.
    3. En Debian, abre una terminal y edita el archivo: 
      sudo nano /etc/grub.d/40_custom
    4. Agrega al final las siguientes 5 líneas: 
      menuentry "NetBSD 11.0 (amd64)" {
    insmod ufs2
    set root=(hd0,gpt8)
    knetbsd /netbsd --root=ld0a
}
    5. Ejecuta: 
      sudo update-grub

    Al reiniciar, verás NetBSD 11.0, Debian y Windows en tu menú de GRUB.

    4. Internet en NetBSD con tu teléfono:

    Conecta tu móvil Android por cable USB y activa "Conexión compartida USB". En NetBSD escribe:

    ifconfig -a          # Verás la interfaz urndis0
dhcpcd urndis0       # Obtener IP y navegación instantánea
